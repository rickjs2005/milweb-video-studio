Este repositório não distribui bibliotecas, modelos, fontes, trilhas, vídeos ou arquivos de skills de terceiros. O código e as instruções incluídos foram escritos para este projeto.

Os links em `skills/milweb-video-studio/references/sources.md` são referências opcionais. Instalar uma ferramenta ou reutilizar ativos requer verificar a licença de sua versão e suas condições próprias. A licença MIT deste pacote não concede direitos sobre esses materiais.

Em particular, verificar a licença própria do motor Remotion; as condições do serviço Higgsfield; os componentes do build FFmpeg; e os direitos de modelos, vozes e músicas. Não presumir que um repositório com muitas estrelas seja auditado ou que uma licença de código cubra mídia de exemplo.

Não há afiliação oficial com os projetos citados.

## Dependências do fluxo local (v0.7.0)

- HyperFrames 0.8.162: Apache-2.0, instalado separadamente.
- GSAP 3.14.2: licença própria GreenSock, instalada separadamente pelo projeto de vídeo. A licença MIT desta skill não cobre essa biblioteca.
- Inter variável, via @fontsource-variable/inter 5.3.0: fonte SIL OFL-1.1, instalada separadamente com a licença do pacote.
- Kokoro ONNX: implementação e modelos/vozes com termos próprios; usar os arquivos oficiais locais.
- faster-whisper e FFmpeg: dependências opcionais/externas conforme o trabalho.

Os templates HTML, a composição demonstrativa e o áudio sintetizado pelo script são originais deste projeto. Não foram copiados arquivos das skills pesquisadas. Os links para receitas externas são referências técnicas; conferir a licença antes de reutilizar código ou ativos.
